Personal Agent

Run it for real

What you need so automations actually fire at 9pm, and what it takes to connect Instagram.

The short answer

1

A computer that never sleeps

Your phone cannot do this. Something must stay awake to watch the clock.

2

The app running on it

Five small programs started by one command.

3

Permission from each app

Instagram will not let software post until Meta approves you.

How the parts fit

The scheduler is the piece that makes automations happen on time. If it is not running, nothing fires.

Where to run it

A small cloud server recommended

Always on, nothing to maintain at home. Providers like Railway, Render, Fly.io, Hetzner or DigitalOcean run this size of app for roughly a few dollars a month. Check their current prices yourself — they change.

Your own computer

Free, but it must stay switched on and online. If it sleeps at night, your 9pm automation does not run.

Your phone

Not possible. A phone cannot keep a server running in the background.

Starting it

On the server, with the project files and Docker installed:

cp .env.example .env
# fill in POSTGRES_PASSWORD and SESSION_SECRET

docker compose up -d

That one command starts all five parts: database, queue, API, worker and scheduler. Open http://your-server:3000 and sign in.

You only set two secrets to begin: a database password and a long random session key. Add an AI key later if you want real answers in Chat instead of the demo model.

Connecting Instagram

This is the slow part, and most of it is paperwork with Meta, not code. Expect days to weeks, not minutes.
1

Make the account professional

A personal Instagram account can never post through the API. It must be a professional (business) account.

2

Create an app on Meta for Developers

This gives you the keys your server will use.

3

Ask for the publishing permission

Called instagram_business_content_publish on the Instagram login path, or instagram_content_publish on the older Facebook login path.

4

Pass App Review

Meta asks for a written explanation and a screen recording showing your app posting. Business verification may also be required.

5

Put the token in your server's settings

It stays on the server, never in the phone app.

Rules that will trip you up

  • Your photo must already be on a public web address when posting. Instagram fetches it; it cannot read a file from your phone.
  • Images must be JPEG, and there are size limits.
  • There is a daily cap on how many posts you may publish through the API.
  • Link, poll and question stickers are not available through the API.
One detail is genuinely unclear right now: whether a linked Facebook Page is still required. Sources disagree, and it depends which login path you use. Confirm it on Meta's own documentation before you build around it.
